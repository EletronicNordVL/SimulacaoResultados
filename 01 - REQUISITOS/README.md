# 01 - Requisitos do Trabalho (N1)

Esta pasta contém a documentação e os requisitos oficiais da avaliação **N1** da disciplina de **Banco de Dados II**.

## 📄 Conteúdo da Pasta
* ****: Documento de especificação do trabalho prático proposto pelo professor Anker D. Lóss.

## 🎯 Objetivo do Trabalho
A partir de um diagrama de classes inicial, o objetivo do projeto é modelar e implementar um banco de dados relacional no MySQL para armazenar dados de simulações físicas de corpos celestes (como Terra e Lua).

## 📋 Atividades Requeridas
1. Desenhar o **Modelo de Dados Lógico**.
2. Desenhar o **Modelo de Dados Físico**.
3. Definir as **Chaves Primárias e Estrangeiras** das tabelas.
4. Criar o **Script de Criação do Banco de Dados**.
5. Formular os **SELECTs** para responder às consultas de **a** até **f**.
