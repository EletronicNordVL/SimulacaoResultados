# 🌌 UniversoN1 - Banco de Dados II

Repositório dedicado ao desenvolvimento e documentação do **Trabalho Prático N1** da disciplina de **Banco de Dados II**.

O objetivo deste projeto é modelar, estruturar e consultar um banco de dados relacional no **MySQL** voltado para o armazenamento e análise de dados de simulações físicas de corpos celestes (como Terra e Lua) ao longo de interações temporais.

## 📁 Estrutura do Repositório
Contém as pastas:
> 01 - REQUISITOS
> 02 - MODELAGEM
> 03 - SCRIPT SQL

## 🚀 Módulos do Projeto

### 1. [01 - REQUISITOS](./01%20-%20REQUISITOS)
Contém as instruções, diagrama de classes base e perguntas analíticas (de **a** até **f**).

### 2. [02 - MODELAGEM](./02%20-%20MODELAGEM)
Contém a modelagem relacional do banco de dados :
* **Modelo Lógico**: Diagrama DER construído no **brModelo**.
* **Modelo Físico**: Especificação DDL e mapeamento de chaves (PK/FK) e restrições ().

### 3. [03 - SCRIPT SQL](./03%20-%20SCRIPT%20SQL)
Contém o script SQL unificado desenvolvido no **MySQL Workbench**:
* DDL para criação da base e das tabelas.
* DML com carga inicial de testes (Simulação Terra x Lua).
* DQL respondendo todas as 6 consultas analíticas solicitadas.

## 🛠️ Tecnologias e Ferramentas
* **SGBD**: MySQL
* **IDE SQL**: MySQL Workbench
* **Ferramenta de Modelagem**: brModelo
* **Linguagem**: SQL (ANSI / MySQL dialect)
