# 03 - Script SQL (MySQL)

Esta pasta contém o script SQL completo para criação, povoamento e consulta do banco de dados .

## 🛠️ Ferramentas e Ambiente
* **SGBD**: MySQL.
* **IDE**: MySQL Workbench (usado para criação, execução e validação dos scripts).

## 📄 Conteúdo da Pasta
* ****: Script contendo a estrutura de banco de dados (DDL), inserção de massa de testes (DML) e todas as consultas solicitadas (DQL). ****

## 🚀 Como Executar o Script no MySQL Workbench
1. Abra o **MySQL Workbench** e conecte-se ao seu servidor MySQL.
2. Abra o arquivo do script no editor de queries.
3. Execute o script completo ().
4. O script irá:
   * Criar a base de dados.
   * Criar as tabelas e com suas restrições.
   * Inserir dados de teste para a simulação com Terra e Lua.
   * Executar os SELECTs referentes às perguntas de **a** até **f** da especificação.
